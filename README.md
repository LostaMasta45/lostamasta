# Losta Masta

Website React dari `losta_masta_spesialis_pembuatan_website.tsx`, dengan Vite, Tailwind CSS, Framer Motion, dan Lucide.

## Pengembangan

```powershell
npm install
npm run dev
```

Ubah `losta_masta_spesialis_pembuatan_website.tsx` di folder proyek ini untuk memperbarui isi, desain, layanan, portofolio, dan animasi. File awal di direktori induk tetap disimpan sebagai referensi.

## Publikasi

Identitas Sites tersimpan di `.openai/hosting.json`. Build produksi menggunakan `npm run build` dan menghasilkan direktori `dist/`. Gunakan kembali identitas Sites yang sama untuk pembaruan berikutnya.

## Batas versi awal

Formulir konsultasi mengikuti file sumber dan menampilkan konfirmasi lokal; belum mengirim data ke email, WhatsApp, atau database. Gambar dan font masih memakai URL eksternal dari file sumber.
